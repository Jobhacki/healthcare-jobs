# Contributing to the Healthcare jobs list

Help healthcare job seekers find openings across patient care and medical offices. Please share the employer's own posting so readers can check the requirements.

## What belongs in this list

Clinical support, caregiving, therapy, medical assistant, patient services, and medical office roles belong here.

## Suggest a job

Include the exact role title, employer's own apply link, location, and any required credential.

[Open the Add a job form](https://github.com/Jobhacki/healthcare-jobs/issues/new?template=add-a-job.yml)

## Report a dead link

Include the healthcare role title, employer, link, and the message or status you see.

[Open the Report a dead link form](https://github.com/Jobhacki/healthcare-jobs/issues/new?template=report-a-dead-link.yml)

## Ground rules

- Use the issue forms above. The table in the README is generated, so a pull request that edits it will be overwritten on the next refresh.
- Links must go to the employer's own career page or hiring system. Links to job aggregators and links with tracking or session parameters are not added.
- Please do not include personal data about anyone.
- We review suggestions by hand and cannot promise a timeline or that every suggestion is added. The employer's page is always the source of truth for a listing.
